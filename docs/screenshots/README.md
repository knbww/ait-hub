# Screenshots

The root [`README.md`](../../README.md) renders these four images from this folder:

| File | What it shows |
|---|---|
| `dashboard.png` | The member dashboard with its draggable, per-member cards (Season, Courses, Profile, Leaderboard, Projects, Deadlines). |
| `copilot.png` | The AIT Copilot widget open over the dashboard. |
| `admin2.png` | The Applications triage list — AI score per applicant, accept / reject. |
| `admin1.png` | The Automations panel — screening stats and run history. |

Tips:
- Capture at a 16:10-ish window (~1440×900) so the cards aren't cramped.
- Seed a little data first so nothing looks empty on camera.
- For the README hero or a portfolio post, a short GIF of the drag-and-drop dashboard or the
  streaming copilot lands harder than a still — save it as `demo.gif` and embed it at the top.
