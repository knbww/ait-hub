# Screenshots

The root [`README.md`](../../README.md) references three images from this folder. Capture
them and drop them in here with these exact filenames so the README renders:

| File | What to capture |
|---|---|
| `dashboard.png` | The member dashboard with several cards visible (Profile, Leaderboard, Season Progress, Heatmap). Reorder a card first so the drag handles read as "customizable". |
| `copilot.png` | The AIT Copilot open mid-stream, with a real answer about AIP or the Academy partially rendered. |
| `admin.png` | The Admin page: the application triage list with an AI score visible, and the Automations panel. |

Tips:
- Capture at a 16:10-ish window (~1440×900) so the cards aren't cramped.
- Seed a little data first so nothing looks empty on camera.
- For the README hero or a portfolio post, a short GIF of the drag-and-drop dashboard or the
  streaming copilot lands harder than a still — save it as `demo.gif` and embed it at the top.
